# Engram Power — OpenAI Integration

Este repositório é um **Engram Power (Agent Plugin 1.0)** compatível com OpenAI (ChatGPT, Assistants API e Custom GPTs).

## Configuração e Nomenclatura
- **Manifesto**: `.openai/assistant.json`
- **Instruções**: `.openai/instructions.md`
- **Padrão de Skills**: `power-{dominio}-{acao}` no diretório `skills/`
